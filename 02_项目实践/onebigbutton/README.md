# 001 · onebigbutton

制作桌面独立大按钮，按一下切换中英文输入。首版采用 USB 有线、CH552G 自研 PCB，Windows 11 + 微信输入法，模拟 Ctrl + 空格；跳过面包板。

## 当前状态

原理图已绘制。用户已修正 USB1 外壳焊盘编号，随后现场检查为 **0 错误、1 个 USB1 ATTRMATCHCODE 警告**，62 个连接引脚和 18 个 NC 引脚符合目标。固件、PCB、外壳和实板验证尚未完成。

查看 [CH552G 原理图资料](硬件设计/CH552G_原理图/README.md)。其中 epro2 是修正前导出；修正后图片和检查记录单独标明，不能把旧导出当成最新现场工程。
