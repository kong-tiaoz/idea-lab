## 本轮范围

保留用户已放置的 U1（CH552G）和 USB1（TYPEC-507DSW-ACP24），包括其库身份、型号、封装、位号、坐标和方向。
新增外围、连线及明确的未连接标记；器件最终标准化由用户完成。本轮没有操作 PCB。

主控采用 USB 5V 供电。V33 是内部 3.3V 电源端，单独去耦，不与 VBUS 短接。
CH552G 内置程序存储和时钟，未使用原 RP2040 方案的外置 Flash、晶振或 USB 串联 27Ω 电阻。

## 连接与使用约定

- J1：外置常开自复位大按钮。1 脚接 BTN_EXT，2 脚接 GND。
- U1.1 / P3.2：BTN 输入，低电平按下；R4 上拉、R5 串联保护、C4 滤波，固件仍需消抖。
- SW1：USB 下载键，通过 R3 10kΩ 将 D+ 拉向 VBUS；按住再上电进入预置 USB BootLoader。正常使用时松开。
- SW2：RST 高电平复位。后续固件配置需保留外部复位功能；下载时亦可使用断电重插。
- U1.11 / P3.4：LED 控制，低电平点亮，仅指示运行或触发，不代表电脑输入法真实中英文状态。
- DP / DM 分别代表 USB D+ / D−；VBUS 为 USB 5V；相同网名电气相连。
- USB1 的 USB 3.x 高速脚和 SBU 脚未使用，已明确标记 NC。

## 已知问题与验证范围

逐脚对账覆盖 18 个器件、62 个连接脚和 18 个 NC 脚，并核实两颗原有器件的身份和位置保持不变。

**USB1 原库存在 PIN2PAD 问题：符号含 28 脚，而本工程封装没有 28 号焊盘。**
按用户“已经放上去的别改”的要求，未更换 USB1 或修改其符号/封装映射，留待器件标准化处理。
这一项未关闭前不能宣称原生 DRC 通过或可投板。其余元件的符号脚号与本工程封装焊盘号已按导出的原生资料对照。

显式保存返回 saved:true。重载确实完成关闭和重开，但其短时就绪检查超时；后续完整现场回读及逐脚对账成功。
没有将这次超时改记为成功。原生工程导出不等于已经重新导入验证；尚无 PCB、制造、固件或实板验证结论。

图签接口曾返回“未应用”，重载后实际可见字段已更新；纸外显示已修正。最终结构/图面检查为零项，短接检查为零项；原始失败回执保留，未改记为成功。详细检查结果见 [验证记录](verification.json)。
