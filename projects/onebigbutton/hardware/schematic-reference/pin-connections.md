# 逐脚连接表（阅读版）

**历史 RP2040 方案，已被 [CH552G 当前连接表](../ch552g/connections.md) 取代。**

在 VS Code 打开本文件后，按 Ctrl+Shift+V 查看。按 Ctrl+F 搜索位号或网名，例如 U1、USB_DP、BTN_N。

每行读作：这个元件的这个脚，接到哪条网络。相同网名需要电气相连；“不连接（NC）”表示该脚单独悬空，不要建立名为 NC 的公共网络。

例如：U1 的 47 脚 USB_DP，接 USB_DP_MCU；U3 的 8 脚 VCC，接 +3V3。

本文件由 [原始 CSV](pin-connections.csv) 转成阅读版，保留全部引脚记录。J1 使用标准 USB-C 逻辑触点名，实际封装仍需核对。
