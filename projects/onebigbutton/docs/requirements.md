# 需求记录

记录日期：2026-11-02

## 已知目标

- 一个外置、独立、便于按下的大按钮。
- 用来切换中英文输入。
- 项目文件由 VS Code 和 Git 统一管理。

## 实现前待确认

- 是当前中文输入法内部的“中文 / 英文”切换，还是系统输入语言切换？
- 目标系统、输入法及用户当前实际使用的切换快捷键。
- USB 有线还是蓝牙；按钮尺寸、手感、预算。
- 是否需要灯光显示中文 / 英文状态。

## 初步建议（待验证）

先考虑 USB 有线原型：按键触发设备发送已验证的键盘快捷键。
这只是候选方案，尚未确定开发板、引脚或快捷键。

发送一次切换快捷键只表示发出了按键，并不证明知道当前输入法状态。
如果需要准确的状态指示，需进一步验证系统接口或电脑端辅助程序。

## 验收目标草案

- 一次有效按压只触发一次切换；长按不连续误触发。
- 按下和释放过程无按键卡住。
- 在目标输入法及常用软件中实测生效。
- 拔插设备后可恢复，普通键盘仍正常使用。
