# 需求记录

记录日期：2026-11-02

## 已知目标

- 一个外置、独立、便于按下的大按钮。
- 用来切换中英文输入。
- 项目文件由 VS Code 和 Git 统一管理。
- 首版采用 USB 有线连接，USB 供电。
- 目标环境：Windows 11、微信输入法。
- 用户当前使用 Ctrl + 空格切换；设备目标为模拟这组按键，实际效果待板上验证。
- 用户熟练使用嘉立创打板，跳过面包板阶段，直接制作 PCB 原型。

## 实现前待确认

- 确认 Ctrl + 空格在目标软件中的具体切换效果及候选词存在时的行为。
- 模块底板还是完整自研 PCB；主控与固件路线尚未选定。
- 按钮尺寸、手感、安装方式与预算。
- 是否需要灯光显示中文 / 英文状态。

## 初步建议（待验证）

USB HID 键盘原型：每次有效按压发送一次 Ctrl + 空格，然后释放全部模拟按键。
USB 连接方式和目标快捷键已由用户提供；主控、引脚及器件尚未确定。
开发板加面包板不再作为首版实施步骤；PCB 应预留下载、复位、测试和机械固定位置。

发送一次切换快捷键只表示发出了按键，并不证明知道当前输入法状态。
如果需要准确的状态指示，需进一步验证系统接口或电脑端辅助程序。

## 验收目标草案

- 一次有效按压只触发一次切换；长按不连续误触发。
- 按下和释放过程无按键卡住。
- 在目标输入法及常用软件中实测生效。
- 拔插设备后可恢复，普通键盘仍正常使用。
